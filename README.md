# R8 BLE Configurator

Android BLE diagnostic/configuration utility for the iSinwheel R8 (`R8-US`).

The repository contains the Android source archive and a GitHub Actions workflow that builds a debug APK.

## Build

Open the **Actions** tab, choose **Build Android APK**, then use **Run workflow**. When the build finishes, download the `R8BLEConfigurator-debug-apk` artifact.
